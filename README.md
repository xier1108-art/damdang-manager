# 담당사업관리

학교시설 담당 사업(계약)을 학교별로 모아 보고 관리하는 Windows 데스크톱 프로그램입니다. Go와 WebView2로 만들었습니다.

## 주요 기능
- **계약 목록**: 학교별 카드로 나눈 목록(묶음 접기·펼치기), 장기계속 총괄·차수 묶음, 열 너비 조정, 칸마다 마우스를 올리면 나오는 복사 버튼(요약명 칸은 본 계약명 복사)
- **캘린더**: 노션 캘린더처럼 주 단위로 이어서 스크롤되는 월 보기, 왼쪽 캘린더 목록에서 보일 캘린더 고르기, 착수일·완수일과 구글 캘린더 일정(회의 등)을 함께 보기, 일정을 눌러 고치거나 두 번 눌러 새로 만들기, 끌어서 날짜 옮기기(구글 캘린더에 바로 반영)
- **문서로 추가·갱신**: 계약서·착공계·납품요구서(PDF·HWP·HWPX·DOCX·이미지)를 Claude API로 읽어 입력칸 자동 채움
- **계약 문서 보관**: 넣은 문서를 데이터 폴더의 `문서\학교\요약명`에 보관하고 상세 화면에서 바로 열기
- **변경 이력**: 문서로 갱신하거나 금액·날짜 등을 고친 내용을 날짜별로 기록
- **노션 동기화**: 노션 데이터베이스와 양방향 동기화
- **구글 캘린더**: 설정에서 Google 계정으로 로그인하면 착수일·완수일을 `(착수) 요약명`, `(완수) 요약명` 종일 일정으로 등록·수정·삭제
- **엑셀 내보내기**, 자동 저장·백업, 라이트·다크 테마(창 제목 표시줄 포함), 창을 닫아도 트레이에서 계속 실행

## 설치
[Releases](../../releases)에서 `damdang-manager-버전.exe`를 내려받아 원하는 폴더에 두고 실행합니다(이름은 `담당사업관리.exe`로 바꿔도 됩니다). 데이터 파일은 exe와 같은 폴더에 만들어집니다. Windows 10/11과 WebView2 런타임(대부분 기본 설치)이 필요합니다.

API 키·토큰은 설정 화면에서 넣으며, 이 PC의 Windows 계정으로 암호화해 저장합니다.
